# დავალება: Todo Manager

## მიზანი
ააწყე ვებ-აპლიკაცია, რომელიც დაგეხმარება დავალებების მართვაში — დაამატო, წაშალო, მონიშნო შესრულებულად. გვერდზე ასევე უნდა ჩანდეს მცირე სტატისტიკა: სულ რამდენი დავალება გაქვს, რამდენი დაასრულე და რამდენი დაგრჩა.

---

## რა უნდა გააკეთო

### HTML
გვერდზე უნდა იყოს:
- სათაური
- input ველი დავალების ჩასაწერად
- ღილაკი "დამატება"
- დავალებების სია (`<ul>`)
- სტატისტიკის ბლოკი (სულ / შესრულებული / დარჩენილი)
- ღილაკი "ყველას წაშლა"

### CSS
- გააფორმე გვერდი ისე, რომ თვალისთვის სასიამოვნო იყოს — აარჩიე ფერები, დაამატე padding, გაამრგვალე კუთხეები
- შესრულებულ დავალებას გადაუსვი ხაზი (`text-decoration: line-through`)
- ღილაკებზე დაამატე hover ეფექტი

### JavaScript

#### ცვლადები
გამოიყენე `const` და `let` სათანადოდ. შექმენი ცვლადები DOM-ის ელემენტებისთვის (input-ი, ღილაკები, სია).

#### მასივი და ობიექტები
დავალებები შეინახე მასივში. თითოეული დავალება იყოს ობიექტი:
```javascript
{
  id: 1,
  text: "ვისწავლო JavaScript",
  completed: false
}
```

#### ფუნქციები
დაწერე ეს ფუნქციები:
- `addTask()` — ამატებს ახალ დავალებას
- `deleteTask(id)` — შლის კონკრეტულ დავალებას
- `toggleTask(id)` — ცვლის სტატუსს (შესრულებული / არა)
- `renderTasks()` — ხატავს დავალებებს ეკრანზე
- `updateStats()` — აახლებს სტატისტიკას
- `clearAll()` — შლის ყველაფერს

#### ლუპები
დავალებების ჩვენებისთვის გამოიყენე `for` ან `forEach`. შესრულებულების დათვლაც ლუპით სცადე.

#### მასივების მეთოდები
გამოიყენე მინიმუმ სამი:
- `push()` — დამატებისთვის
- `filter()` — წაშლისთვის ან გაფილტვრისთვის
- `forEach()` ან `map()` — სიის ხატვისთვის
- `find()` — კონკრეტული დავალების მოსაძებნად
- `length` — დასათვლელად

#### ობიექტებთან მუშაობა
ყოველი ახალი დავალებისთვის შექმენი ცალკე ობიექტი. სტატუსის შესაცვლელად პირდაპირ შეცვალე თვისება (`task.completed = true`).

## სად გამოიყენება ეს რეალურ ცხოვრებაში

ეს პატარა პროექტი ზუსტად იმავე პრინციპით მუშაობს, რაზეც დიდი აპლიკაციები დგას:
- **მონაცემები მასივში** — Facebook ასე ინახავს პოსტებს, Spotify — სიმღერებს
- **ფილტრაცია** — Gmail-ში წერილების გაფილტვრა იგივე `filter()` მეთოდით ხდება
- **CRUD** (Create, Read, Update, Delete) — ნებისმიერი აპის ხერხემალია, იქნება ეს ბანკის აპი თუ ინსტაგრამი
- **DOM-ის განახლება გვერდის გადატვირთვის გარეშე** — როცა ლაიქს აჭერ, გვერდი ხელახლა არ იტვირთება, მაგრამ რიცხვი მაინც იცვლება — სწორედ ეს პრინციპი
